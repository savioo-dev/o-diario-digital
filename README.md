📰 O Diário Digital

Projeto de uma página de jornal digital desenvolvido com **HTML5 e CSS3**, como parte dos meus estudos de desenvolvimento Front-end.

📌 Sobre o projeto

O Diário Digital é uma página que simula a estrutura visual de um jornal, apresentando uma notícia sobre o impacto da Inteligência Artificial no jornalismo brasileiro.

O projeto foi desenvolvido com foco na aplicação de conceitos de tipografia, estilização de textos e organização de conteúdo.

🚀 Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts (Open Sans)

✨ Conceitos aplicados

- Estruturação semântica com HTML.
- Seletores e propriedades CSS.
- Tipografia com `font-size`, `font-family` e `font-weight`.
- Unidades relativas `em` e `rem`.
- Pseudo-elemento `::first-letter`.
- Alinhamento e espaçamento de textos.
- Design responsivo com Media Queries.
- Flexbox para centralização do conteúdo.


🎯 Objetivo

Praticar e aprimorar conhecimentos em HTML5 e CSS3, desenvolvendo interfaces web com organização, estilização e responsividade.
